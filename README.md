# HMS Module 3 — Departments & Services + Settings

Frontend-only React app for **Module 3** of the Hospital Management System.

## Features

| Page | Description |
|------|-------------|
| **Dashboard** | Summary cards, bar/pie charts, dept overview, opening hours & escalation quick view |
| **Departments** | List, add, edit, delete departments with status toggle. Filterable & searchable. |
| **Services** | Manage clinical services with department linkage, fees, durations and type tags. |
| **Consultation Types** | Card-grid view with colour pickers, duration sliders and status toggles. |
| **Settings** | 4 tabs — Hospital Info, Opening Hours, Languages, Escalation config. |

## Stack

- **React 18** + **Vite 5**
- **Tailwind CSS 3**
- **React Router 6**
- **Lucide React** (icons)
- **Recharts** (charts)

## Development

```bash
npm install
npm run dev
```
